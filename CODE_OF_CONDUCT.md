# Code de conduite

## Notre engagement

Nous voulons un espace ouvert et accueillant pour contribuer à Sentinelle, que ce soit ta première pull request ou une correction plus tard dans le mois. Nous nous engageons à faire de la participation une expérience sans harcèlement, quel que soit l'âge, le corps, le handicap, l'origine ethnique, l'identité ou l'expression de genre, le niveau d'expérience, la nationalité, l'apparence, la race, la religion ou l'identité et l'orientation sexuelles.

## Comportements attendus

- Faire preuve de bienveillance et de patience, surtout avec les personnes qui découvrent Git.
- Accepter les retours sur le contenu proposé, et expliquer les tiens avec respect.
- Se concentrer sur ce qui est le mieux pour le projet et pour les personnes qui apprennent.
- Relire ce que tu soumets. Une contribution générée sans la comprendre n'aide personne.

## Comportements inacceptables

- Langage ou images à connotation sexuelle, et avances non sollicitées.
- Trolling, insultes, attaques personnelles ou politiques.
- Harcèlement public ou privé.
- Publier des informations privées (adresse, clé d'API, mot de passe, token) sans accord explicite.
- Toute conduite qui serait jugée inappropriée dans un cadre professionnel.

## Responsabilités

Le mainteneur peut retirer un commentaire, fermer une pull request ou bannir temporairement ou définitivement une personne dont le comportement ne respecte pas ce code.

## Portée

Ce code s'applique dans les issues, les pull requests, les discussions du dépôt, et dès qu'une personne représente le projet en public.

## Application

Signale un comportement inacceptable en privé au mainteneur : [https://github.com/arispacco](https://github.com/arispacco). N'ouvre pas d'issue publique pour une situation sensible. Toutes les plaintes seront examinées et donneront lieu à une réponse jugée nécessaire et adaptée. Le mainteneur garde confidentielle l'identité de la personne qui signale.
